# Data

The competition data is not included in this repository because it belongs to the
course competition (Columbia APAN 5200 Predictive Analytics Competition on Kaggle).

Place the two files here to run the code:

- `analysis_data.csv`: 40,000 customers, 22 features + `monthly_spend` target
- `scoring_data.csv`: 10,000 customers to predict

Features include demographics (age, region, education), credit profile (credit score,
credit limit, income, tenure, card type) and behavior (transaction count, average
transaction value, online shopping frequency, travel frequency).
